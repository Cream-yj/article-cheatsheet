# 可打印速查表的排版与交付

## 风格依据

参考了用户提供的[《从推理到 Agent：信用分配综述速览》小红书帖子](https://www.xiaohongshu.com/explore/6ad6a98a000000002902ca2c)，2026-10-22 查看了正文和四张图片。观察到的形式是四页横向学术速查表：第一页总览，后续多栏整理分类、机制、公式、对比、建议和边界，标题和提示框使用少量区分色。

之后查看了同一作者的 [MemOPD 帖子](https://www.xiaohongshu.com/explore/6acc5151000000001a0222bf) 与主页其他速查表封面。用户明确偏好其中的学术讲义质感，并认为初版的浅色背景、圆角卡片和大号无衬线标题过于模板化。因此默认采用以下学术排版规则；“LaTeX 风格”是版式目标，不据图片断言参考作者使用了哪款软件。

只借鉴信息组织与版面原则。不要复制帖子作者署名、水印或逐字转写其图表；具体内容以本次待总结文章为依据，也不默认核实了帖子所引用的论文结论。

## 内容组织：2026-10-23 样本观察

本轮对照 CoPE 与信用分配综述各四页，抽读 MemOPD、WorldMemArena 的首页、第二页和末页，并结合用户提供的 StateMemBench 首页截图。以下是对速查表组织方式的观察，不是对这些论文结论的独立核验，也不推断作者的实际生成提示词。

- [CoPE](https://www.xiaohongshu.com/explore/6ad3f406000000002a0049a3)：首页问题与方案并列；后续围绕设计选择、为什么有效、与替代方案的区别、实验设置、开销、结果与阅读提示组织，穿插代码例子、算法与原图。
- [MemOPD](https://www.xiaohongshu.com/explore/6acc5151000000001a0222bf)：首页用动机图连接问题与方案，并单独澄清本文的 memory 含义；机制页把关键定义与流程放一起；末页解释结果、贡献位置和容易误读的数值。
- [WorldMemArena](https://www.xiaohongshu.com/explore/6acef30f0000000015016307)：首页呈现评测缺口、诊断方案、与既有 benchmark 的区别和主要发现；后续围绕生命周期、任务、数据、指标、失败诊断展开，并以阶段对照收束。
- [信用分配综述](https://www.xiaohongshu.com/explore/6ad6a98a000000002902ca2c)：首页提供问题和分类地图；后续分类轴、方法家族、挑战对应关系、推荐表与选型路径占主要篇幅。部分节次沿用原文，但入口和查阅路径经过重新组织。

可复用原则：固定读者要回答的问题，按文章类型选择内容模块，不固定逐章缩写模板。首页先提供主线；后续按机制理解、证据解释和回查需要展开。问题与方案要在内容上对应，不只添加两个标题。方法论文突出关键操作及设计理由；基准论文突出能力缺口、任务与指标如何测到它；综述突出分类维度与适用条件。

布局随内容变化：宽原图配问题/方案窄栏，或通栏动机图下接问题、方案与概念澄清；后续宽表/图搭配多栏解释。把相关证据与解读放近，允许跨章节取材，不把不同长度的信息塞进等高框。颜色、线框用于区分问题、方案、证据等语义角色，避免仅为装饰增加模块。

## 可用工具与格式

- 使用当前环境可靠的 PDF 生成路径。需要 PDF 生成/渲染工具时，读取可用的 `pdf` 技能；使用文档运行库前可通过 `load_workspace_dependencies` 定位环境。
- 环境支持时优先用 XeLaTeX 排版，交付 `.tex` 与 PDF。新建项目优先使用可用的 `create_latex_project`，在独立文件夹保存 `main.tex`，再使用 `compile_latex_document` 检查；本地 XeLaTeX 可用于导出。打开预览不等于编译成功。其他工具也可使用，但需实现同样的字体、栏式、表格和留白逻辑。
- 已有成熟排版环境时复用。缺少编译器不必为了总结文章安装庞大工具链，可选择其他可靠路径，或如实交付已完成的文字与源文件。
- 简单结构图可用矢量或代码绘图；公式、表格和中文正文使用真实文字排版，避免用生成式图片承载精确文本。

## 页面设计

- 默认 A4 横向、白底黑字，正文优先三栏；宽图和宽表可通栏或两栏。段落按研究逻辑连续组织，不把每节包进等大的卡片。栏间保持约 5–7 mm 间距，必要时使用极细分隔线。
- 中文正文用宋体或同类书面衬线字体，英文正文用 Times 一类衬线字体；公式使用数学字体。不要全篇采用网页 UI 式无衬线字体。优先选择环境已有字体，保留可替换配置。
- 正文通常 9–10.5 pt，小标题约 10–12 pt、文章标题约 15–18 pt。主标题不过度占据页面；来源注释可以略小，但必须可辨。信息过多优先删重复解释或增加页数，不持续缩小字体。
- 层级主要依靠编号、小标题、加粗、段落与细横线。默认仅用一种低饱和强调色；额外颜色只表达确有必要的分类或状态。不铺整页浅色背景，不用阴影、装饰色条或大量圆角框。淡色底纹仅用于少量需要突出的结论或定义。
- 原文已有图表默认直接裁切 PDF 截图，保留图内原文标注、坐标轴、图例、表头与数据；不用中文重绘图或重新录入表格替代。裁掉图外英文 caption，改用可编辑的中文图注，保留原编号、关键条件与单位。普通叙述翻译成中文，只保留 memory、agent、LLM、GPT、模型与方法名称等必要英文及论文常用术语，不重复保留整段英文图注。建议 300 dpi 以上或矢量裁切，标注原文图表编号和页码，中文解释放图外。宁可增加页数，也不把原图缩到难以阅读；交付源文件时一并保留裁切图。
- 仅在确需整理者自制机制图时，围绕真实输入、操作、输出或状态变化布局，使用简洁矢量线条和紧凑标签；不要为了填版面添加无实质信息的流程框。
- 每页页眉分为三段：左侧仅“Paper Cheatsheet”，中间文章标题，右侧已核实的论文来源链接与录用或发表状态（会议、年份、Main/Findings 等）。标题过长时页眉用明确短标题，完整原文标题在首页标题区保留；标题必须相对整页宽度真正居中（左右页边距对称），优先用独立左、中、右锚点；不要用不等宽左右列之间的剩余空间居中代替页面居中。三段统一为一行，文字过长时精简标签或短标题，避免换行与碰撞。论文链接不限平台，使用可访问且确认对应本文的 paper link 即可；可显示来源名或简短链接，优先复用用户提供的有效来源。已有可用链接时不额外寻找 arXiv，不显示平台缺失或待核实占位。发表状态未知时不编造会议或录用结论。
- 首页标题区使用一个通栏细边框和很浅的灰蓝底色，允许轻微圆角；这是信息集中区，不扩展为整页卡片风。左侧放简称、完整原文标题、作者和主要机构，必要时标共同一作/通讯作者；右侧放研究主线和简短的“作者相关积累”，以具体相关作品及作者关系支撑判断。作者与机构较多时可换行或把详细证据移至末页，不靠极小字体硬塞。
- 每页页脚放简短来源标识、页码与整理/核验日期；关键区块给章节/图表/公式定位，完整链接集中在来源区。标题区的发表状态与相关作品应可点击回查。
- 整理者自制表格（须标注）优先三线表与浅细分组线，避免深色整行表头和无语义的交替底色；数字按列对齐，必要重点用加粗。按查阅需求选择列，列宽适应中文换行。长表可分主题拆开并重复表头，避免跨页后丢失列含义。
- 公式适当留白并解释符号；长公式改为跨栏或拆行。不要把标题留在页末、正文挤到下一页。
- 最后一页可放阅读导航或条件明确的选择路径；如果原文没有可靠选择依据，改用“比较时应检查的条件”。

## 渲染检查与文件

保留可编辑源文件及最终 PDF，用户要求图片时再导出逐页 PNG。用户指定的目录与命名优先；否则选择项目适当的独立输出目录，避免覆盖已有笔记。

检查实际 PDF 的所有页面，可使用页面拼图先看整体，再放大检查密集区域：

1. 中文无缺字，文本和上下标没有乱码。
2. 无重叠、裁切、内容溢出，表头、公式和脚注可读。
3. 分类轴、箭头和图例对应正确；表格没有在换行或分页后改变含义。
4. 页数与阅读负担合理，来源位置清楚，文件内容与聊天速览一致。
5. 页眉左侧只有 Paper Cheatsheet，中间标题相对整页居中，右侧与其保持足够间距，三段在同一行。原图本体裁切完整、图内原文清晰，中文 caption 与图表对应且无残留或重复的英文 caption；图表编号和页码正确。
6. 相邻表格顶部对齐；小标题和所属正文留在同栏。优先按完整主题安排栏位，避免自动平衡将短句或来源拆到下一栏。检查整体是否仍像研究讲义，而非彩色网页卡片或宣传海报。

修复后重查受影响的页面。最终提供 PDF 与源文件的可点击绝对路径，并简要说明实际阅读范围。不能把编译日志、未渲染的源代码或空模板当作完成的 PDF。
